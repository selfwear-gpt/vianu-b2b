# Skills-Archiv

Hier liegen Skills aus `mattpocock/skills`, die zu dieser Website nicht passen. Claude lädt diesen Ordner nicht, ihre Beschreibungen belegen also keinen Platz im Kontext.

| Skill | Grund |
|---|---|
| `triage` | Für eingehende Meldungen von Dritten. Hier gibt es keine. |
| `teach` | Lernbegleiter für den Nutzer, kein Teil der Seitenarbeit. |
| `ask-matt` | Wegweiser über den vollen Skill-Satz. Für dieses Projekt gilt `docs/agents/skill-auswahl.md`. |
| `improve-codebase-architecture` | Für Umbau größerer Anwendungen. Die Skripte dieser Seite sind klein. |

Zurückholen: `git mv .claude/skills-archiv/<name> .claude/skills/<name>`.
